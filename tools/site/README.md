# الصفحة الرئيسية للموقع — التصميم

`index.html` هو التصميم المرجعي: صفحة هبوط كاملة بالعربية من اليمين لليسار،
بلقطات حقيقية من النظام وبلوجو الشركة وألوانها.

```bash
node shoot.js   # يصيّر التصميم: home-desktop.png (الصفحة كاملة) و home-fold.png
node qa.js      # يفحص كل قسم هندسياً: تمرير أفقي، نص مقصوص، عناصر خارج الإطار
```

يحتاج الخطوط واللقطات من `tools/deck/` (fonts/ و assets/ و shots/).

## بناء التصميم في Figma

`figma/*.js` ثلاثة سكربتات تُنفَّذ بأداة `use_figma` بالترتيب، وتبني الصفحة
بإطارات auto-layout حقيقية ورموز ألوان — لا صورة مسطّحة.

1. `figma-1-tokens-nav-hero.js` — الرموز، إطار الصفحة، شريط التنقّل، البطل
2. `figma-2-stats-features-flow.js` — الأرقام، الميزات، دورة العمل
3. `figma-3-roles-mobile-cta-footer.js` — الأدوار، الهاتف، نداء الإجراء، التذييل

السكربتان الثاني والثالث يحتاجان `pageFrameId` الذي يُعيده الأول.

الصور تُترك إطارات فارغة مسمّاة باسم الملف المطلوب، لأن رفع الصور إلى Figma
محجوب من هذه البيئة. استبدلها يدوياً أو بأداة `upload_assets` من بيئة غير محجوبة.

> هذه السكربتات **لم تُختبر** — حساب Figma الحالي (مقعد View على خطة Starter)
> يسمح بست استدعاءات شهرياً وقد استُهلكت. تحتاج مقعد Full أو Dev لتشغيلها.
